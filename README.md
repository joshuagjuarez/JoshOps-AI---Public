# JoshOps AI

## Technology that preserves meaning and serves people

JoshOps AI develops PothOS around cognitive sovereignty, memory continuity and
human control. The purpose is to reduce noise, recover useful signal and help
people develop their own work and help others.

This repository is the company project index. The product's technical
documentation and collaboration belong in its own repository.

## Free. Always.

Official PothOS software is intended to remain free of charge. The project
opposes charging people for PothOS and exploitation of their private cognitive
information. Prospective runtime terms are being defined; see
[PothOS license status](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/blob/main/LICENSE_STATUS.md).

The current PothOS repository contains mission, design and contribution
documentation. The standalone runtime source has not been released.

Project privacy and legal boundaries remain separate. A link between projects
does not share accounts, private memory, case records or authority.
